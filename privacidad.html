Política de privacidad

omarchy-calendar · última actualización: 21 de octubre de 2026

omarchy-calendar es una aplicación de escritorio personal que muestra los eventos de Google Calendar en el panel del reloj de Omarchy. Esta política explica qué datos toca, para qué los usa y dónde se guardan.

Responsable

Francisco González Moreno · franciscogonzalezmoreno@gmail.com

Qué datos se usan

  • Datos de Google Calendar, solo de la cuenta que autoriza la aplicación: título, descripción, ubicación, fecha y hora, color y estado de los eventos, y la lista de calendarios de esa cuenta. El permiso solicitado es https://www.googleapis.com/auth/calendar, que permite leer y escribir eventos.
  • Credenciales OAuth: un token de acceso y un token de refresco, que Google entrega al usuario al autorizar la aplicación.

Para qué se usan

  • Mostrar los eventos en el calendario local de la aplicación.
  • Enviar notificaciones locales de escritorio antes de que empiece un evento.
  • Permitir crear o modificar eventos desde la propia aplicación, cuando el usuario lo hace.

Dónde se guardan

  • Únicamente en el equipo del usuario, en su carpeta personal: ~/.config/omarchy/calendar/credentials.json (permisos 600, solo lectura para su dueño) y ~/.local/state/omarchy/calendar/events.json.
  • No existen servidores del desarrollador ni servicios intermedios. La aplicación habla directamente con la API de Google.
  • Los datos no se comparten con terceros, no se venden, no se usan para publicidad ni para elaborar perfiles, y no se emplean para entrenar modelos de inteligencia artificial.
  • La aplicación no recoge datos de uso, analítica ni telemetría.

Uso limitado de datos de Google

El uso que omarchy-calendar hace de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado (Limited Use). Los datos de Google Calendar se usan exclusivamente para las funciones visibles de la aplicación descritas arriba.

Conservación y eliminación

  • Los datos permanecen en el equipo hasta que el usuario los borra o revoca el acceso.
  • Para revocar el acceso: myaccount.google.com/permissions.
  • Para borrar la copia local: eliminar la carpeta ~/.config/omarchy/calendar/ y el archivo ~/.local/state/omarchy/calendar/events.json.

Cambios

Si esta política cambia, la fecha de la parte superior se actualizará y los cambios se publicarán en esta misma página.
